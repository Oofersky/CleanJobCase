Частые вопросы

Откуда берутся вакансии?

Из открытых данных портала «Работа в России» по региону 39 (opendata.trudvsem.ru).

Это ответы работодателя?

Нет. Сервис формулирует вопросы, которые стоит задать. Ответы даёт только работодатель.

Можно ли сохранить отчёт?

Да. После входа отчёты пишутся в вашу историю: можно открыть прошлый прогон или скачать JSON.

Нужна ли регистрация?

Да, для платформы и резюме. Логин придумываете сами, почта нужна при регистрации. Чужие отчёты вам не видны.

Что такое файл JSON в источнике?

Это пример набора вакансий для тестирования системы. Поиск в сети загружает актуальные объявления региона 39.
